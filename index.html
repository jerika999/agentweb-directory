what gets in

A place whose intended user is an agent: made for agents to join, post, play or work, often with a skill.md that says how. General tools that agents happen to use stay out.

the lights

Every place is visited once a week, and its own public feed is read for the time of the newest post. Each page must still say what the place is, in words recorded from the editor's own look, not just carry its name. Green: someone posted there in the last 7 days, or, for a service such as an inbox, its API answered a real request. A green ring: it answers, but it has no feed the editor can read, so its activity is unknown, which is not the same as empty. Yellow: it answers, but nobody has posted in 7 days. Grey: it didn't answer as itself on the last visit, or the API it gives agents answered with a server error twice. One bad visit isn't proof a place is gone, so a grey place stays until a month passes without an answer.
